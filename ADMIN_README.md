# Инструкция по использованию админ-панели

## Доступ к админ-панели

1. Перейдите по адресу: `/admin`
2. Введите пароль (по умолчанию: `admin123`)
3. Для изменения пароля установите переменную окружения `ADMIN_PASSWORD` в файле `.env.local`

## Управление контентом (Фото/Видео)

1. После входа выберите вкладку **"Контент (Фото/Видео)"**
2. Вы можете редактировать:
   - Видео для фабрик (Surxon, Maroqand, Kamalak)
   - Другие медиа-файлы в JSON формате
3. После изменений нажмите **"Сохранить контент"**

### Формат видео для фабрик:
```json
["/Surxon/Surxon_1.png", "/Surxon/Surxon_2.png", "/Surxon/Surxon_3.png"]
```

## Управление вакансиями

1. Выберите вкладку **"Вакансии"**
2. Нажмите **"+ Добавить вакансию"** для создания новой
3. Заполните:
   - **Название вакансии** - заголовок
   - **Описание** - подробное описание
   - **Ссылка (URL)** - ссылка на детальную информацию или форму подачи заявки
   - **Активна** - чекбокс для активации/деактивации вакансии
4. Нажмите **"Сохранить"** для сохранения вакансии
5. Нажмите **"Удалить"** для удаления вакансии

## Просмотр вакансий

Пользователи могут просмотреть все активные вакансии на странице `/vacancies` и перейти по ссылкам для получения дополнительной информации.

## Визуальный редактор (GrapesJS Studio)

1. Выберите вкладку **"Визуальный редактор"**
2. Используйте визуальный редактор для создания и редактирования веб-страниц:
   - Перетаскивайте элементы из панели блоков
   - Редактируйте стили через панель стилей
   - Управляйте слоями через панель слоев
   - Настраивайте атрибуты элементов через панель атрибутов
3. Нажмите **"Сохранить проект"** для сохранения изменений
4. Проекты автоматически сохраняются в `public/data/studio-project.json`

## Безопасность

⚠️ **Важно**: В продакшене обязательно:
- Измените пароль по умолчанию
- Используйте переменную окружения для пароля
- Рассмотрите возможность добавления более надежной системы аутентификации
- Добавьте HTTPS для защиты данных
